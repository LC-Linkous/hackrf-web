# Code of Conduct

This is a small project used in a teaching lab. Many people here are meeting
hardware, serial ports, or GitHub for the first time.

- Be kind. Assume questions are asked in good faith and answer them that way.
- Be patient with mistakes, your own included.
- Keep discussion about the work, not the person.
- No harassment, insults, or sharing of anyone's private information.

If something's wrong, report it privately through GitHub (*Report content* on
the item) or contact the maintainer at https://github.com/LC-Linkous. Reports
are taken seriously and handled discreetly.
